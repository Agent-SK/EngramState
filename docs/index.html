01 · OVERVIEW

Compile once. Reuse at runtime.

Many tool-use systems repeatedly process static tool information for every request. ES separates reusable knowledge from the live user query, enabling a lighter runtime path designed with mobile inference in mind.

⚡

Less repeated work

Avoid processing the same tool descriptions on every interaction.

🧠

Reusable states

Prepare compact tool-specific states offline and load them when needed.

📱

On-device first

Designed around latency, storage, and runtime constraints of mobile deployment.

02 · METHOD

A simple runtime path.

A lightweight retriever selects a candidate state from the user query. The runtime loads that state and generates the function call without repeatedly prefilling the full tool specification.

Technical note 05 · Mobile systems

What worst-case latency looks like on Galaxy S25 Ultra

Average latency is not enough for an agent with retries. We measured the retry path on a real Samsung Galaxy S25 Ultra with RWKV-7 1.5B.

Why retries matter

EngramState validates generated calls and may try a Corrective State or another retrieved candidate. This makes average latency only part of the story. A deployment-oriented evaluation should ask how bad the tail can get.

Single-call bound

Under Top-4 retrieval, a single-call query can make at most five total attempts: the initial Base attempt plus up to four retries. Execution terminates after the Corrective path for the final candidate.

Multi-call bound

For multi-call execution, each candidate's Base and Corrective states are attempted at most once across calls. Under Top-4 this yields at most eight total attempts.

A useful way to read the table: EngramState's single-call worst-case path with four retries (8.204 s) is still faster than one initial Prompt (Top-4) attempt (9.047 s) in this mobile measurement.

Why the per-attempt TTFT stays flat

Each EngramState retry loads a compact candidate state and runs from the short live query. The prompt baseline repeatedly pays the cost of long tool-conditioning context. This is why repeated retries amplify the gap rather than erasing it.

What “on-device” means here

The mobile evaluation uses the Galaxy S25 Ultra as the inference target. The model execution and state-loading path measured for these results run locally on the device; the numbers are not remote API round-trip times.

For a product claim, we prefer this wording over the looser phrase “server-free”: fully on-device model inference with no remote model serving in the measured execution path.

What remains outside this benchmark

These measurements characterize model/state execution and retry behavior. A production app can add unrelated costs such as Android intent dispatch, app startup, sensor access, UI animation, or network-bound tools. Those should be measured separately rather than folded into model TTFT.

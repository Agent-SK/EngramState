Technical note 03 · Compression

How far can recurrent states be compressed?

State reuse removes repeated prompt compute, but persistent state files become a new systems cost. Quantization determines whether that trade is practical on a phone.

EngramState stores one Base State and one Corrective State per tool. For RWKV-7 1.5B, the combined FP16 representation is approximately 24.76 MiB per tool. At 100 tools, that would already exceed 2.4 GiB.

Why channel-wise quantization?

The WKV recurrent state is not a static model weight. It is a dynamically generated activation, and its channels can have very different value ranges. EngramState therefore quantizes channels independently, using a separate range per channel rather than one global scale.

This is also why weight-oriented methods such as GPTQ do not directly transfer: GPTQ relies on statistics for static weights, whereas a recurrent state is produced dynamically from a specific prompt. AWQ's intuition—protect important channels through scaling—is closer to what channel-wise state quantization already exploits.

Four bits: the practical default

RWKV-7 1.5B · Base + Corrective
FP16  : 24.76 MiB / tool
4-bit :  6.19 MiB / tool

Four-bit storage gives an approximately 4× reduction. The choice is practical rather than a claim that four bits are the mathematical limit.

Two-bit channel-wise storage remains dramatically better than the naïve alternatives, but the accuracy drop is larger.

Why 4-bit in the released design? Four-bit values are naturally byte-aligned—two values per byte—and fit existing mobile inference stacks cleanly. Three-bit packing can save more storage, but it complicates packing/unpacking and deployment kernels.

Storage vs runtime memory

The state repository grows linearly with the number of tools, but EngramState does not keep the entire repository resident during inference. The retriever selects candidates and only the chosen state is loaded for the current attempt. Persistent storage therefore scales with the catalog while active state memory remains bounded by the execution path.
